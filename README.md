# GunBalatro (가제: **THE LITANY** / 연도)

> 1인칭 · three.js · 모바일 세로 우선 · GitHub Pages 정적 호스팅
> **발라트로의 덱빌딩 수학**을 **볼터 라이플의 탄약 관리**로 번역한 로그라이크 슈터.

---

## 한 줄 정의

> 어두운 폐건물 골목을 자동으로 전진하며, **가방에서 뽑은 탄을 탄창에 어떤 순서로 넣을지** 결정해
> 다가오는 좀비를 **닿기 전에** 사살하는, 순서(order)가 곧 수학인 1인칭 덱빌딩 슈터.

## 설계 3원칙

1. **모든 파라미터는 결정을 만든다.**
   플레이어가 신경 쓰는 숫자가 늘어나는 비용은, 그 숫자가 만들어내는 *선택*으로만 정당화된다.
   결정을 만들지 않는 수치(명중률·반동·탄속·스태미나 등)는 전부 삭제했다.
2. **곱셈은 오직 하나 — 온도.**
   데미지는 덧셈으로만 자란다. 온도도 덧셈으로만 자란다. 최종 계산에서 단 한 번 곱한다.
   "얼마나 예열하고 언제 큰 걸 쏘는가"가 게임의 전부다.
3. **순서(order)가 1급 시민이다.**
   발라트로에서 카드 순서는 대부분 무의미하다. 여기서는 온도가 발사마다 누적되므로
   **동일한 5발을 어떤 순서로 넣느냐가 데미지를 3~10배 갈라놓는다.** 이것이 이 게임의 존재의의다.
