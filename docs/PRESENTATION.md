# 연출 · UI 기획

> 이 게임에서 **연출은 장식이 아니라 정보 채널**이다.
> 온도는 총의 색으로, 거리는 좀비의 크기로, 데미지는 화면 전체의 폭력으로 전달한다.
> HUD 숫자를 못 봐도 상황을 알 수 있어야 한다.

### 가로 모드
뷰포트 좌 60% / 조작부 우 40%. 세로가 기본이며 가로는 동등한 대안(열화판 아님)이다.

### 카드 디자인 (44×62pt)
정보는 딱 3개: **탄종 색 + 탄종 아이콘 + 등급 로마숫자**. 데미지 수치는 카드 하단에 8pt로 작게.
- AP 철갑 = 무광 은색 / 쐐기 아이콘
- INC 소이 = 주황 / 불꽃
- HE 고폭 = 황토 / 파열
- SANC 축성 = 백금+금 / 아퀼라(쌍두독수리)

색맹 대응: 아이콘 형태만으로 4종이 구분되며, 설정에 **패턴 오버레이** 옵션(사선/점/격자/무지) 제공.

## 2. 사격 시퀀스 — ms 단위 타임라인

한 발당 **420ms**. 5발 탄창 = 2.1초 + 정산 0.6초.
설정에서 **×1 / ×2 / ×3 / 즉시** 선택 가능 (기본 ×1, 2회차부터 ×2 권장 토스트).

### 2.1 장전 (사격 버튼 누른 직후, 1회 · 700ms)

| t (ms) | 연출 |
|---|---|
| 0 | 트레이 카드들이 탄창 슬롯으로 빨려 들어감 (스태거 60ms 간격, ease-in-back) |
| 300 | 탄창 삽입 사운드 (금속 *채캉*), 화면 하단 8px 상승 후 복귀 |
| 420 | 노리쇠 전진 (*철컥*) + 총 스프라이트 X축 12px 후퇴→복귀 |
| 560 | 3D 조명 전체 −20% 페이드 (연출 집중) |

## 3. 온도 시각화 (총 스프라이트 / 3D 모델)

온도는 **총열 머티리얼의 emissive 값 + 색**으로 표현된다. 숫자를 안 봐도 알 수 있어야 한다.

| 온도 | 단계명 | 총열 색 | Emissive | 추가 연출 |
|---|---|---|---|---|
| 1.0 ~ 3.0 | 냉각 (COLD) | #6b6f74 무광 강철 | 0.00 | — |
| 3.0 ~ 8.0 | 가열 (WARM) | #7a2c10 암적 | 0.25 | 총열 끝만 미약하게 |
| 8.0 ~ 16.0 | 적열 (HOT) | #ff6a12 주황 | 0.85 | 아지랑이 셰이더 시작, 화면 가장자리 미세 왜곡 |
| 16.0 ~ 30.0 | 백열 (SEARING) | #ffc44d 노랑 | 1.60 | 스파크 파티클, 총 주변 볼륨 글로우, 총 미세 떨림 |
| 30.0 ~ | 성화 (SANCTIFIED) | #fff6e0 백열 | 2.60 | 총 전체 발광, 화면 전역 웜 그레이딩, 낮은 그르렁 사운드 루프 |

- 단계가 바뀌는 순간 **총이 한 번 크게 번쩍**하고 사운드가 한 단계 무거워진다.
  → 플레이어가 "임계점을 넘었다"는 것을 촉각적으로 안다. 용광로 심장(온도 10) 같은 부착물과 연결된다.
- 온도 게이지는 **로그 스케일**로 표시한다 (1~50이 한 바에 들어가야 하므로). 눈금은 3 / 8 / 16 / 30 위치에 각인.

## 4. 탄 삽입 UX (핵심 조작)

이 게임의 유일한 정밀 조작. **오조작이 곧 데미지 손실**이므로 취소 가능해야 한다.

1. **탭** — 트레이의 탄을 탄창 다음 빈 슬롯에 넣는다. 슬롯에 번호 배지 ①②③.
2. **탄창 슬롯 탭** — 그 탄을 트레이로 되돌린다. 뒤 번호가 자동으로 당겨진다.
3. **탄창 슬롯 드래그** — 순서 재배치. 드래그 중 나머지가 실시간으로 밀린다.
4. **롱프레스 (0.4초)** — 탄 상세 (데미지·온도·특수) 팝오버.
5. **실시간 예상 피해 표시** — 탄창 슬롯 우측에 `≈ 3,948` 이 항상 갱신된다.
   순서를 바꾸면 숫자가 즉시 변한다. **이것이 "순서가 중요하다"를 가르치는 가장 강력한 장치다.**
   - 확률 요소(도박꾼의 성구, M3 미소모)는 기대값으로 계산하고 `≈` 대신 `~` 표기 + 범위 툴팁.
6. **사격 확정** — 버튼 롱프레스 없이 단일 탭. 대신 **탄창이 다 안 찼으면 확인 다이얼로그** 1회.

> **자동 정렬 버튼을 넣지 않는다.** "최적 순서 자동 배치"는 게임 자체를 삭제하는 기능이다.
> 대신 실시간 예상 피해로 플레이어가 스스로 최적을 찾게 한다.

## 5. 온레일 이동 구간 연출

- **손전등 1개** (스포트라이트, cone 38°, 감쇠 22m). 손전등이 흔들리며 걷는 리듬을 만든다.
- 카메라: 카트뮬-롬 스플라인 + 보행 사인파 (상하 0.04m / 2.1Hz, 좌우 0.02m / 1.05Hz).
  전투로 이어지는 마지막 구간에서는 이 진폭이 **달리기**로 커진다 (§5.1).
- **어둠이 렌더링 예산이다.** 손전등 원뿔 밖은 거의 검게 처리 → 드로우 콜과 텍스처 부담 동시 절감.
- 환경음: 물방울, 먼 비명, 삐걱임, 자신의 발소리·호흡. **음악 없음** (전투에만 음악).
- **다음 적 예고**: 벽의 핏자국 방향/양, 뒤집힌 바리케이드, 긁힌 자국 → 아키타입별 고유 데칼.
  (주자 = 길게 끌린 자국 / 비대체 = 넓은 얼룩 / 무리 = 다수의 손자국)
- 갈림길: 복도 끝 문 2개. 문 위 **스프레이 표식**(◆ 개수)과 **문틈으로 새어나오는 빛 색**
  (T1 흰빛 / T2 주황 / T3 붉은빛)이 위험도를 색으로도 알린다.

### 5.1 전투 진입 — 적을 보고 멈춘다

전투는 "적이 나타나는" 사건이 아니라 **"달려오다 멈추는"** 사건이다. 순서가 중요하다:
적이 먼저 보이고, 그 다음에 브레이크를 밟는다. 반대로 하면 아무리 잘 만든 흔들림도
"적이 튀어나왔다"로 읽힌다.

1. **적은 처음부터 거기 서 있다.** 문을 지나는 구간이 시작될 때, 그 구간이 끝나는
   자리(레일 곡선의 끝점)에 적을 **미리 세운다**. 전투 시작에 생성하지 않는다.
   전투 시작 거리는 `previewStartDistance()` 로 미리 계산하므로 전투가 실제로
   시작될 때 적이 한 픽셀도 움직이지 않는다. 복도도 새로 만들지 않는다 — 배경은 같다.
2. **안광만 안개 밖에 둔다.** 몸통은 안개(FogExp2 0.046)를 그대로 타지만 안광은
   `fog: false` 로 두고 거리 감쇠를 직접 건다(`1/(1+(d/19)^1.7)`). 안개는 40m 밖을
   통째로 지우지만 이 곡선은 60m 밖에도 **불씨 두 점**을 남긴다. 그래서
   달려가는 동안 점 → 안광 무리 → 실루엣 순서로 드러난다.
3. **달린다.** 이 구간만 보행 사인파 진폭을 좌우 3.6배 / 상하 3배로 키운다.
   달려온 몸이 아니면 급제동이 급제동으로 안 읽힌다.
4. **급브레이크.** 짧은 진동이 아니라 **관성**이다. 1.7초에 걸쳐 감쇠 1.85 로
   앞뒤 0.62m · 좌우 0.34m · 롤 0.155rad 를 왕복시킨다(3~4번 보인다).
   흔들림 설정(강/약/끔)이 그대로 곱해진다 — 끔이면 아무 일도 일어나지 않는다.
5. **구도 이동도 미끄러뜨린다.** 이동 중에는 시선축이 화면 한가운데지만 전투에서는
   위쪽 띠의 한가운데다. 한 프레임에 바꾸면 이미 보이던 적이 화면 높이의 22% 만큼
   위로 튄다 → 인셋을 0.25초에 걸쳐 보간한다(브레이크와 같은 시간).

## 6. 광과민성 · 접근성 (필수 사양)

번쩍임이 게임의 정체성인 만큼, **안전 옵션은 타협 대상이 아니다.**

| 설정 | 기본값 | 내용 |
|---|---|---|
| **화면 번쩍임** | 강 | 강 / 약(α 0.88→0.25, 지속 2배) / **끔**(플래시 없이 총구 발광만) |
| **화면 흔들림** | 강 | 강 / 약(진폭 30%) / 끔 |
| **색수차·왜곡** | 켬 | 끔 선택 시 전부 비활성 |
| **연출 속도** | ×1 | ×1 / ×2 / ×3 / 즉시 결과 |
| **햅틱** | 켬 | 끔 |
| **색맹 패턴** | 끔 | 탄종에 사선/점/격자 패턴 오버레이 |
| **글자 크기** | 표준 | 표준 / 크게 (+15%) |

- `prefers-reduced-motion: reduce` 감지 시 **첫 실행에서 자동으로 "약" 프리셋을 제안**하는 다이얼로그.
- 첫 실행 시 무조건 광과민성 경고 화면 노출 (WCAG 2.3.1 — 초당 3회 초과 플래시 회피).
  → 사격 속도 ×3(발당 140ms ≈ 7Hz)는 위험하므로, **×3 선택 시 플래시를 자동으로 "약"으로 강등**한다.
- 모든 사운드 정보에 시각 대응물이 존재한다 (무음 플레이 가능).

## 7. 사운드 설계 (최소)

| 레이어 | 내용 |
|---|---|
| 이동 | 환경음만. 음악 없음 |
| 전투 진입 | 낮은 오르간 지속음 페이드인 |
| 전투 중 | 심박 퍼커션. **거리에 비례해 템포 상승** (30m 60BPM → 5m 150BPM) |
| 사격 | 온도 단계마다 발사음 샘플 교체 (5종). 뜨거울수록 저역이 두껍고 잔향이 길다 |
| 처치 | 오르간이 장조로 해결되며 종소리 1타 |
| 즉사 | 전부 컷 → 이명 |

> 사운드가 전달하는 유일한 *고유* 정보는 **거리(심박 템포)** 다.
> 나머지는 전부 시각 정보의 보강이다. 무음으로도 완주 가능해야 하기 때문이다.
